# Аналіз домену (Domain Analysis)

## Загальний опис домену

Система дозволяє користувачам бронювати та купувати квитки на музичні концерти.
**Основний бізнес-процес:**

- організатори створюють концерт
- система публікує подію з розкладом, місцем, цінами та категоріями квитків
- користувачі переглядають доступні події
- користувач може додати квиток у корзину, оформити замовлення та оплатити його
- після покупки генерується електронний квиток (QR або інший код)
- користувач отримує підтвердження про замовлення

---

# Піддомени

## 1. User & Identity (Auth)

Відповідає за:

- реєстрацію й логін
- доступ до системи
- ролі: User, Organizer, Admin

**Сутності:**

- User
- Role

## 2. Events (Події)

Керує інформацією про концерти:

**Функціонал:**

- створення й редагування концертів
- опис (назва, дата, виконавець, місто)
- план залу/типи квитків

**Сутності:**

- Event
- Venue
- SeatCategory (наприклад Fan Zone, VIP, Standard)

## 3. Ticketing (Бронювання квитків)

Керує:

- наявними квитками
- бронюванням
- уникненням подвійних бронювань
- генерацією QR/унікального коду

**Сутності:**

- Ticket
- Reservation

## 4. Orders & Payments

Відповідає за:

- створення замовлень
- оплату
- валідацію стану

**Сутності:**

- Order
- OrderItem
- Payment

## 5. Notifications

Сервіс для:

- email підтверджень
- інформаційних сповіщень
- пуш-сповіщень у майбутньому

**Сутності:**

- Notification
- NotificationTemplate

## 6. Analytics (майбутній піддомен)

Розраховує:

- статистику продажів
- популярність подій
- конверсії переглядів → продажів

**Сутності:**

- Report
- Metric
